账户与组：用户、组、策略分开记

本地账户

保存在本机 SAM，常表示为“计算机名\用户名”。同名账户不等于同一 SID。

域账户

由 Active Directory 域管理，常表示为“域名\用户名”。/domain 表示切换操作范围，不表示操作任意远程主机。

net user用户账户管理

查询 / 新建 / 修改 / 删除+

管理本机用户账户；加 /domain 后对当前主域执行。创建账户与把账户加入组是两项操作。SID 标识安全主体，RID 是 SID 末尾的相对标识；访问令牌保存本次登录的身份、组与特权。

[] 表示可选，| 表示二选一。语法说明中的“用户名”“密码”要替换为实际值。

设置登录限制与账户属性

/uniquepw:n
记住的历史密码数量。
/lockoutthreshold:n

/lockoutwindow:n
失败计数器的复位时间。
/lockoutduration:n

/forcelogoff:分钟|no

sc.exe服务控制管理器

CMD

创建与修改配置

CMD
:: 前提：C:\Lab\ExamSvc.exe 是符合 Windows 服务接口的服务程序
sc.exe create ExamSvc binPath= C:\Lab\ExamSvc.exe type= own start= demand obj= "NT AUTHORITY\LocalService" DisplayName= "Exam Lab Service"

:: 修改已有服务配置
sc.exe config ExamSvc start= auto
sc.exe config ExamSvc start= disabled
sc.exe config ExamSvc binPath= C:\Lab\ExamSvc-v2.exe
sc.exe description ExamSvc "Training service"
sc.exe failure ExamSvc reset= 86400 actions= restart/60000

sc create 不会凭空生成服务程序，也不会把任意普通 exe 自动变成服务。路径含空格时，存入 ImagePath 的可执行路径自身还应有引号。failure 示例的 reset 单位是秒，actions 延迟单位是毫秒。

运行控制、删除与远程操作

CMD

sc.exe stop ExamSvc
sc.exe pause ExamSvc
sc.exe continue ExamSvc

sc.exe delete ExamSvc

:: 远程 SCM：前缀是两个反斜杠
sc.exe \\LAB-SRV query ExamSvc

查看与设置服务权限

CMD
sc.exe sdshow ExamSvc
sc.exe sdset ExamSvc "<完整SDDL>"

sdshow 查看服务对象安全描述符；sdset 修改权限，示例中的占位 SDDL 必须替换为实际有效内容。

核心参数

type= own|share|kernel|filesys
独立进程服务 / 共享进程服务 / 内核驱动 / 文件系统驱动。
start= auto|demand|disabled
自动 / 手动 / 禁用。另有 delayed-auto；boot、system 主要用于驱动。
binPath= 路径
服务程序路径及参数。
obj= 账户 / password= 密码
运行服务的身份及相应凭据；不是安装者身份。
depend= 服务1/服务2
依赖项名称用 / 分隔。
DisplayName= 名称
显示名称，可与服务键名不同。
error= ignore|normal|severe|critical
系统启动期间服务启动失败的严重程度。
state= active|inactive|all
query 的状态范围；与 start= 的启动类型不是一套取值。
语法要点：等号属于参数名，等号后有空格

正确：start= auto；错误：start=auto。Windows PowerShell 5.1 中 sc 可能是 Set-Content 的别名，学习与执行时显式写 sc.exe。

taskkill终止一个或多个进程

按 PID / 按名称 / 按条件 / 强制 / 子进程 / 远程+
CMD
:: 按 PID；一次指定多个 PID
taskkill /pid 4816

:: 按映像名；强制；包含子进程
taskkill /im notepad.exe
taskkill /pid 4816 /f
taskkill /pid 4816 /t

:: 先过滤再终止；通配符配合过滤条件
taskkill /fi "USERNAME eq LAB-PC\examuser" /im notepad.exe
taskkill /fi "IMAGENAME eq note*" /im * /f

taskkill /s LAB-SRV /u EXAM\examadmin /pid 4816

这些是独立用法。终止进程可能丢失未保存数据；/t 包括目标进程启动的子进程。

/pid n
按进程 ID 选择，可重复给多个 /pid。
/im 名称

/fi "条件"
限定要终止的进程集合。
/f
强制终止；不是“查询完整信息”。
/t
终止目标与其子进程。
/s /u /p
远程主机及凭据参数。
远程与本地有差别

远程终止总是强制执行，不以是否写 /f 为准。远程不支持 STATUS 和 WINDOWTITLE 过滤。受保护进程或权限不足时，命令仍可能失败。

过滤器与比较运算符

PID / SESSION / MEMUSAGE
数值条件：eq、ne、gt、lt、ge、le。MEMUSAGE 单位 KB。
CPUTIME
累计 CPU 时间，格式 HH:MM:SS，支持数值比较。
IMAGENAME / USERNAME
映像名 / 用户名，一般用 eq、ne。
SERVICES / MODULES
服务名 / 模块名，一般用 eq、ne。
STATUS
RUNNING、NOT RESPONDING、UNKNOWN；远程不支持。
WINDOWTITLE / SESSIONNAME
窗口标题；SESSIONNAME 仅列于 tasklist 支持的过滤器中，不要直接套用到 taskkill。
运算符记法

eq 等于，ne 不等于，gt 大于，lt 小于，ge 大于等于，le 小于等于。多个 /fi 条件共同限定结果；过滤表达式要用引号包住。

    Time = $Record.TimeCreated
    Computer = $Record.MachineName
    Id = $Record.Id

# 将事件 XML 转为按字段名访问的对象，兼容 1102 的 UserData
function Convert-EventRecord {
  param([System.Diagnostics.Eventing.Reader.EventRecord]$Record)
  $xml = [xml]$Record.ToXml()
  $row = [ordered]@{
    Time = $Record.TimeCreated
    Computer = $Record.MachineName
    Id = $Record.Id
    RecordId = $Record.RecordId
  }
  foreach ($item in $xml.Event.EventData.Data) {
    if ($item.Name) { $row[[string]$item.Name] = [string]$item.'#text' }
  }
  if ($xml.Event.UserData) {
    foreach ($item in $xml.Event.UserData.SelectNodes('.//*[not(*)]')) {
      $row[$item.LocalName] = $item.InnerText
    }
  }
  [pscustomobject]$row
}

$start = (Get-Date).AddDays(-7)
try {
  Get-WinEvent -FilterHashtable @{
    LogName='Security'; Id=1102,4719; StartTime=$start
  } -ErrorAction Stop |
    ForEach-Object { Convert-EventRecord $_ } |
    Select-Object Time,Computer,Id,SubjectUserName,SubjectLogonId,
      SubcategoryGuid,AuditPolicyChanges
} catch {
  if ($_.FullyQualifiedErrorId -like 'NoMatchingEventsFound*') {
    Write-Warning '时间窗口内无匹配记录，继续导出当前安全日志。'
  } else { throw }  # 权限或通道错误不可当作无记录。
}

# 导出会写入一个新证据文件，不清除源日志；需要日志读取权限。
$exportDir = Join-Path $env:USERPROFILE 'Desktop\IR-Logs'
New-Item -ItemType Directory -Path $exportDir -Force | Out-Null
$exportPath = Join-Path $exportDir ('Security-{0}.evtx' -f (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
& wevtutil.exe epl Security $exportPath
if ($LASTEXITCODE -ne 0) { throw '安全日志导出失败，请检查权限和目标路径。' }
Get-FileHash -LiteralPath $exportPath -Algorithm SHA256
# 本地清除前的日志可能已丢失，另查 WEF / SIEM 留存。
